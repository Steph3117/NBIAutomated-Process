Overview

This tool helps match and categorize emails using a validation CSV and a contact list with VANIDs. It supports browser-only functionality with no backend.

How It Works

  1. Upload your Validation CSV (must contain EMAILS and STATUS columns).
  2. Upload your Contacts CSV (must contain PreferredEmail and VANID columns).
  3. Customize filenames for the outputs (optional).
  4. The tool generates three categorized CSVs: VALID, INVALID, and RISKY.

Column Requirements

FileRequired Columns
Validation CSVEMAILS, STATUS
Contacts CSVPreferredEmail, VANID

Status Mappings

The following status strings are automatically mapped to categories:

  • VALID: Valid
  • INVALID: Address Invalid, Domain Invalid, Account Invalid, Mailbox Full, Accept-All, Disposable
  • RISKY: Role Address, Unknown

3. Reading a CSV File

async function readCSVFile(file) {
  return new Promise((resolve, reject) => {
    Papa.parse(file, {
      header: true,
      skipEmptyLines: true,
      complete: results => resolve(results.data),
      error: reject
    });
  });
}

This async function uses PapaParse to parse a CSV file and return an array of objects, where each object represents a row with headers as keys.

4. Downloading a CSV File

function downloadCSV(data, filename) {
  const csv = Papa.unparse(data);
  const blob = new Blob([csv], { type: 'text/csv' });
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = filename;
  link.textContent = `Download ${filename}`;
  document.getElementById('response').appendChild(link);
  document.getElementById('response').appendChild(document.createElement('br'));
}

This function converts the data back into CSV format, creates a downloadable blob, and dynamically adds a download link to the page.
