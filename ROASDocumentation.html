📈 ROAS Tool – Full Documentation

What Is This Tool?

The ROAS (Return on Ad Spend) Tool is a browser-based utility designed to calculate donation outcomes by OriginCodeName. It compares ActBlue donor data with NBI user data to evaluate the performance of Campaigns ran by NBI.

How It Works

  1. You select a Creation Date to be included on every output row.
  2. You upload two files:
    • ActBlue CSV containing donation records (with Donor Emails and Amounts).
    • NBI CSV containing contact data (with PreferredEmail and OriginCodeName).
  3. The tool matches emails from NBI against ActBlue records.
  4. Each NBI record is enriched with the corresponding donation amount and the selected creation date.
  5. A summary is created for each unique OriginCodeName, showing:
    • Total Donated
    • Average Donated
    • Number of Donors

Input File Formats

FileRequired ColumnsDescription
ActBlue CSV Donor Email, Amount Donation records with emails and amounts in dollars.
NBI CSV PreferredEmail, OriginCodeName Internal contact list with source tracking information.

Output Files

  • Updated NBI CSV – Adds:
    • Creation Date (from the date picker input)
    • Amount (from ActBlue, matched by email)
  • Summary CSV – Aggregates by OriginCodeName:
    • Total Donated (sum of matched amounts)
    • Average Donated (only among donors)
    • Number of Donors (count where donation > 0)

    A final row labeled TOTAL includes grand totals and overall averages.

Matching & Calculation Rules

  • Email addresses are matched after converting to lowercase and trimming whitespace.
  • Only ActBlue rows with numeric Amount and non-empty Donor Email are used.
  • If an NBI email has no match, its amount is set to 0.00.
  • Donors with zero amount are included in the final CSV but excluded from average and count in the summary.
  • The OriginCodeName is grouped as Unknown if blank or missing.

How to Use the Tool

  1. Go to the ROAS Calculator page.
  2. Select the Creation Date (this will be added to all rows in the output).
  3. Upload your ActBlue CSV and NBI CSV.
  4. Click Process.
  5. After processing, download buttons will appear for:
    • Updated NBI CSV
    • Summary CSV

Best Practices

  • Always verify column headers are correctly named.
  • Pre-clean CSVs to remove duplicate or malformed entries.
  • Ensure all emails are in lowercase and consistently formatted (the script will normalize them, but better input = better output).

function parseCSV(file) {
  return new Promise((resolve, reject) => {
    Papa.parse(file, {
      header: true,
      skipEmptyLines: true,
      complete: results => resolve(results.data),
      error: err => reject(err)
    });
  });
}

function getSummaryIncludingZeros(data) {
  const summary = {};

  data.forEach(row => {
    const origin = row["OriginCodeName"] || "Unknown";
    if (!summary[origin]) {
      summary[origin] = { total: 0, count: 0, totalIndividuals: 0 };
    }
    summary[origin].totalIndividuals += 1;
  });

  data.forEach(row => {
    const origin = row["OriginCodeName"] || "Unknown";
    const amount = parseFloat(row["Amount"]);
    if (!isNaN(amount) && amount > 0) {
      summary[origin].total += amount;
      summary[origin].count += 1;
    }
  });

  const summaryRows = Object.entries(summary).map(([origin, stats]) => ({
    OriginCodeName: origin,
    "Total Donated": `$${stats.total.toFixed(2)}`,
    "Average Donated": stats.count > 0 ? `$${(stats.total / stats.count).toFixed(2)}` : `$0.00`,
    "Number of Donors": stats.count,
    "Total Individuals in Source": stats.totalIndividuals
  }));

  const totalAmount = summaryRows.reduce((sum, row) => sum + parseFloat(row["Total Donated"].replace('$', '')), 0);
  const totalDonors = summaryRows.reduce((sum, row) => sum + row["Number of Donors"], 0);
  const totalIndividuals = summaryRows.reduce((sum, row) => sum + row["Total Individuals in Source"], 0);
  const avgDonation = totalDonors > 0 ? totalAmount / totalDonors : 0;

  summaryRows.push({
    OriginCodeName: "TOTAL",
    "Total Donated": `$${totalAmount.toFixed(2)}`,
    "Average Donated": `$${avgDonation.toFixed(2)}`,
    "Number of Donors": totalDonors,
    "Total Individuals in Source": totalIndividuals
  });

  return summaryRows;
}

function renderSummary(summaryRows) {
  const container = document.getElementById('results');
  container.innerHTML = '<h2>Summary by OriginCodeName</h2>';

  const table = document.createElement('table');
  table.innerHTML = `
    <tr>
      <th>OriginCodeName</th>
      <th>Total Donated</th>
      <th>Average Donated</th>
      <th>Number of Donors</th>
      <th>Total Individuals in Source</th>
    </tr>
  `;

  summaryRows.forEach((row) => {
    const tr = document.createElement('tr');
    tr.innerHTML = `
      <td><strong>${row["OriginCodeName"]}</strong></td>
      <td>${row["Total Donated"]}</td>
      <td>${row["Average Donated"]}</td>
      <td>${row["Number of Donors"]}</td>
      <td>${row["Total Individuals in Source"]}</td>
    `;
    if (row["OriginCodeName"] === "TOTAL") {
      tr.style.fontWeight = "bold";
      tr.style.borderTop = "2px solid #000";
    }
    table.appendChild(tr);
  });

  container.appendChild(table);
}

Triggers download of two CSVs: one with enriched NBI data and one with summary stats, both using PapaParse to convert to CSV.

function triggerDownload(csvString, filename) {
  const blob = new Blob([csvString], { type: 'text/csv' });
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = filename;
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
}
